# 重生禮儀（宜蘭）公開首頁

對外宣傳用的公開網站（https://rebirth-yilan.vercel.app/），放：尋墓雷達、宜蘭公立塔位費用計算器、禮儀用品代訂範例、火化・禮廳即時查詢（huohua.html）。
- 梅園塔位方位查詢（meiyuan.html）：**首頁不放卡片**、搜尋引擎不收錄，只給拿到網址的人使用（負責人 2026-10-14 指定）。

- 內部工具系統（liyi-system）不在這裡，也不要連過去。
- 代訂頁只放範例照片與價錢，沒有管理或下訂畫面。
- 照片中的喪家姓名、遺照、車牌一律打馬賽克後才放上來。
- 火化・禮廳即時查詢（負責人 2026-10-14 指定）：資料由負責人 Google Cloud 台灣機房的代查程式即時讀公所公開網頁（原始檔在 liyi-system 的 `crem/index.js`，需允許本站網址）；只送場所與日期，不顯示任何姓名、禮儀公司、地址。日時對沖（巳～酉時）紅底標示，規則與 liyi-system 殯奠吉課排定相同，日柱計算原封不動複製自該處，不可改寫。
- 梅園塔位方位查詢（負責人 2026-10-14 併入）：功能與對照表照搬負責人原本的工具（依號碼前 4–6 碼判斷坐向，長的優先），資料來源為負責人提供之梅園塔位清單，對照表不可自行增改；只把外觀改成本站和風。
